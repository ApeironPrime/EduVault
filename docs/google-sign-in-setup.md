## One-time Firebase Console setup

1. Open Firebase project `appeduvault` → **Authentication** → **Sign-in method**.
2. Enable **Google**, select a project support email, then save.
3. Open **Project settings** → **Your apps** → Android app `com.example.eduvault` and verify both SHA values above. Add any missing fingerprint.
4. Download the updated `google-services.json` and replace `app/google-services.json`.
5. Uninstall the old debug app from the emulator, then run the app again.

The app reads `default_web_client_id` generated by the Google Services plugin; the OAuth web client ID is no longer duplicated in Kotlin source.
